# 输出与存档契约

## 输入处理

接受目标日期、持仓与原始逻辑、相对成本位置、当日交易与当时依据、昨日复盘、重点方向或材料。公开市场数据默认主动获取。未提供个人输入时不追问、不编造，在第⑤步标记无法评价。

同一股票在frontmatter与正文统一使用`名称（代码）`标识。

## 先说结论

固定用六个短字段回答，不扩写成长摘要：

- **市场：** 当前市场状态与风险偏好
- **风格：** 当前主导交易风格
- **主线：** 真实主线，允许为0
- **机会：** 次日最值得跟踪的机会
- **风险：** 当前最大风险
- **仓位：** 最终仓位立场（无冻结模型时只用档位）

### Fact Ownership / Decision-Preserving Compression

完整事实只在一个负责章节展开一次：②拥有Driver/结构证据与R事实；③只写生命周期、最大反证、升级/降级；④只写同行/核心相对优势；⑥只写池子角色与动作条件；⑦只写场景触发和执行；“数据限制”只写缺口与对判断的影响。decision-changing重大事实必须保留一次完整版，但其他章节只能用D/R ID和增量动作引用，不重复事故/公告/价格故事。

标准完整报告目标`<=8500`字符；`>8700`进入输出预算审查。V2.4.6过程建议记录`output_compression_audit`（`report_chars/target_chars/fact_owner_status/decision_changing_facts`）。若`report_chars>8700`，必须额外记录`output_budget_exception`，至少包含`irreducible_sections/decision_or_risk_chains/why_each_extra_section_changes_action/compression_attempted`。该例外只用于真正不可压缩的复杂日，不能以“证据很多/候选很多/写得更完整”作为理由。

正式输出不得出现“近线淘汰”栏目。`main_themes`只保存第③步确认的真实主线；允许为空。最终重大反证扫尾不新增正文步骤：若命中改变决策的事实，直接更新③/④/⑥/⑦；若未命中，仅在“数据限制”的`material_news`行简短记录扫尾状态，禁止再写一段重复总结。

## 盘前更新

盘前只输出隔夜新增变量、计划变化、未变部分、风险提示和仓位立场变化。没有新日K时注明技术指标沿用上一完整交易日，不重新计算。

## 存档与历史兼容

本Skill使用独立存档路径：`archive_root`依次取本次明确目录、`REVIEW_OUTPUT_DIR`、`<project_root>/outputs/a-stock-trading-review`。环境变量值本身就是最终根目录，不再拼接子路径。**所有新文件只写入当前`archive_root`，旧名称目录永不写入。**

为保持从旧构建升级后的历史连续性，仅在以下条件同时满足时启用一次只读兼容：本次没有明确目录、没有`REVIEW_OUTPUT_DIR`、当前默认目录中找不到上一完整复盘。此时允许到同一`project_root`下的`outputs/a-stock-review-audit`读取上一完整交易日最新`review-*.md`作为`legacy_read_root`。该旧目录只读、不迁移、不修改；一旦新目录已有可用上一复盘，优先新目录且不再回退旧目录。

`project_root`只从当前`cwd`解析：若`git rev-parse --show-toplevel`成功则用Git顶层，否则直接用`cwd`。不得搜索其他项目、Skill安装目录或全磁盘。

完整复盘写`<archive_root>/YYYY-MM-DD/review-HHmmss.md`；盘前更新写`premarket-HHmmss.md`。不得覆盖，冲突时加`-01`等后缀。选定目录不可写时不切换路径，正常输出并报告失败原因。

用户明确“不保存/不落盘/只输出”时仅关闭本次写入，仍可按上述规则读取上一完整交易日最新`review-*.md`。旧存档缺少`review_schema`时视为legacy v1；必须直接读取既有frontmatter，不修改或迁移旧文件。若上一复盘来自`legacy_read_root`，`previous_review`可以引用其实际只读来源，但本次新报告仍只能写入当前`archive_root`。

## Frontmatter与隐私

V2新增且只保持必要字段：`review_schema: "2.0"`、`dominant_style`、`position_stance`；继续保留`market_state/main_themes/core_pool/watch_pool/previous_review/data_completeness/privacy`及日期、模式元数据。

默认`privacy: redacted`，不保存身份、资金总额、持仓数量、精确成本/成交价/盈亏比例。允许保存股票、动作类别、逻辑、相对成本分档和条件。只有用户本次明确授权才保存其指定精确字段。

## 交付检查

草稿必须在临时路径运行：

```powershell
python scripts/validate_review_output.py --input <draft.md>
```

Validator只检查结构与明确约束，不用regex判断主线、催化、龙头或仓位在经济上是否正确。质量判断由`evals/blind-evaluator.md`负责。
